# High Performance Computing Practice
[English](README.md) | [简体中文](README_zh.md)

This repository contains the lab code, course guidebooks, and related materials for the Fall 2025 course *High Performance Computing Practice*.

## Course Overview

The course focuses on performance analysis, parallel programming, and matrix multiplication optimization in Linux, covering C basics, debugging, processes/threads, OpenMP, MPI, and application optimization.

## Lab Notes

- `lab08` is the HPL benchmark and is not organized separately in this repository.
- `lab09` covers performance testing and porting on Huawei Kunpeng processors and is closely related to the earlier labs.
- `lab03` to `lab06`, and `lab10` mostly reuse the `lab03/how-to-optimize-gemm` framework, so some shared files are kept in those directories.

## Repository Structure

- `guidebook/`: course guidebooks and lab instructions.
- `lab01/`: Linux OS and shell command labs.
- `lab02/`: C programming in Linux labs.
- `lab03/`: debugging and matrix multiplication optimization labs.
- `lab04/`: Linux process programming labs.
- `lab05/`: Linux thread programming labs.
- `lab06/`: OpenMP programming labs.
- `lab07/`: MPI labs.
- `lab03/how-to-optimize-gemm/`: the main matrix multiplication optimization framework.
