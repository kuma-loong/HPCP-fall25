- 掌握top、ps等工具的使用

## 2. 实验内容

- 练习top、ps、pstree使用，掌握基本的使用方式，理解命令输出的含义

## 3. 程序运行时间测量：time命令

### 3.1 Shell内置time和GNU time

time 在 Linux 下是比较常用的命令，可以帮助我们方便的计算程序的运行时间，对比采用不同方案时程序的运行性能。在 Linux 系统上，使用 time 时，可能会遇到三种版本：

```text
# 1. Bash
time is a shell keyword
# 2. Zsh
time is a reserved word
# 3. GNU time
time is /usr/bin/time

```

可通过 type 命令查看time的类型。

```text
~$ type time
time is a shell keyword

```

GNU time 工具路径是 `/usr/bin/time` ，使用时需使用绝对路径，该命令的输出跟直接运行time命令个类似，但内容更多，功能更强大。 man time 看到的手册内容也是GNU time命令。

- 更详细的统计信息

- 更丰富的格式输出

- 支持保存统计数据到文件

### 3.2 子进程的cpu时间

time命令不会记录子进程的cpu时间，如果是多进程的程序，输出的cpu时间只是主进程的。统计程序中所有进程的cpu时间，有两种方式：

- 代码中使用`clock_t times(struct tms *buffer)`等函数计时

- 使用perf等性能分析工具： `perf stat -e task-clock,cpu-clock ./your_program`

## 4. 注意事项

- top、ps、pstree的使用可以用man查看手册，了解主要的应用场景和选项。也推荐一个小工具[tldr](https://tldr.sh/)可以列出工具的常用选项和说明。

- 查看进程运行时的状态，可以开两个终端，一个终端执行应用程序，另一个终端执行top、pstree等应用。矩阵需要大一点，要保证有足够的时间执行测试命令，进程结束后相关的信息就看不到了。

- 本实验实现的fork_gemm.c，虽然用到了多进程，cpu利用率上升了，但进行重复的计算。多进程加速矩阵乘法，需要对矩阵分块，不同进程计算不同的块，最后通过进程间通信汇总结果数据。
