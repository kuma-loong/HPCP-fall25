# 实验7：MPI并行编程

## 1. 实验目的

- 掌握MPI编程模型和应用场景，掌握MPI常用的命令和API

- 能够应用MPI编程模框架并行化GEMMM

## 2. 实验内容

- 安装MPI框架，运行示例代码，掌握MPI的基本使用

- 使用MPI在单节点实现DGEMM：`C=A*B`，无需考虑系数alpha和beta。

  - 需要通过mpi_test_data.m中测试用例，矩阵C初始为0。

  - 需输出矩阵A、B、C。

  - 需课上检查4*4测试用例执行。

## 3. 实验原理

### 3.1 MPICH安装

```text
sudo apt install mpich  mpich-doc -y

```

### 3.2 矩阵乘法的实现

先阅读：[MPI实现PI的计算cpi.c](https://github.com/pmodels/mpich/blob/d1ffcd3babe17819853fc21ab85aa3eb695bdab9/examples/cpi.c) ，学习主要API和基本的代码框架。

主进程

- 初始化矩阵A、B、C

- 通过点对点通信API将矩阵数据发送给其他进程

- 等待子进程计算结束，接收各子进程的计算结果汇总

- 在主进程中将矩阵A、B、C打印输出，确认结果跟给的数据一致

非主进程

- 接收矩阵A、B、C，可以printf接收到的数据确认通信是否正确

- 分块计算

- 将计算结果发送给主进程
